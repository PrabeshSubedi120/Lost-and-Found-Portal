## Deployment Steps

### 1. Push to GitHub

```bash
git add .
git commit -m "Prepare for Render deployment"
git push origin main
```

### 2. Create Render Account

- Go to [render.com](https://render.com)
- Sign up using your GitHub account

### 3. Deploy on Render

#### Option A: Using render.yaml (Recommended)

1. In Render dashboard, click "New" → "Blueprint"
2. Connect your GitHub repository
3. Render will automatically detect the `render.yaml` file
4. Click "Deploy"

#### Option B: Manual Setup

1. Click "New" → "Web Service"
2. Connect your GitHub repository
3. Configure:
   - **Name**: `lostfound-portal`
   - **Environment**: `Python 3`
   - **Build Command**: `chmod +x build.sh && ./build.sh`
   - **Start Command**: `cd lostfound_project && gunicorn lostfound_project.wsgi:application`

### 4. Database Setup

1. In Render dashboard, click "New" → "PostgreSQL"
2. Configure:
   - **Name**: `lostfound-db`
   - **Database Name**: `lostfound_db`
   - **User**: `lostfound_user`
   - **Plan**: Free

### 5. Environment Variables

Add these in your Render web service settings:

| `SECRET_KEY`             | (Auto-generated by Render)              |

## Troubleshooting

### Build Errors

- Check build logs in Render dashboard
- Ensure all dependencies are in `requirements_production.txt`

### Database Issues

- Verify DATABASE_URL is properly linked
- Check PostgreSQL service status

### Static Files Not Loading

- Ensure `python manage.py collectstatic` runs in build process
- Check WhiteNoise configuration

### Admin Login Issues

- Verify environment variables are set correctly
- Check admin credentials in Render settings
