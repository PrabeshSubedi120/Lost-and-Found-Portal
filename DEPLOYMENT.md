# 🚀 Deployment Guide for Lost and Found Portal

## 📋 Pre-Deployment Checklist

### ✅ Issues Fixed:

- [x] Static files directory created
- [x] Production settings configured
- [x] Security settings enabled
- [x] Database configuration updated
- [x] Deployment files created

## 🌐 **Recommended Free Hosting: RENDER**

### **Step 1: Prepare Your Repository**

1. **Push all changes to GitHub:**

   ```bash
   git add .
   git commit -m "Add deployment configuration"
   git push origin main
   ```

2. **Verify these files are in your repo:**
   - `render.yaml`
   - `requirements_production.txt`
   - `lostfound_project/settings_production.py`
   - `Procfile` (for Heroku backup)
   - `runtime.txt`

### **Step 2: Deploy on Render**

1. **Go to [render.com](https://render.com)**
2. **Sign up/Login with GitHub**
3. **Click "New +" → "Blueprint"**
4. **Connect your GitHub repository**
5. **Render will automatically detect the `render.yaml`**
6. **Click "Apply"**

### **Step 3: Environment Variables (Auto-configured)**

- `SECRET_KEY`: Auto-generated by Render
- `DATABASE_URL`: Auto-configured from PostgreSQL
- `DJANGO_SETTINGS_MODULE`: Set to production settings

## 🔄 **Alternative: Heroku Deployment**

### **Step 1: Install Heroku CLI**

```bash
# Windows
winget install --id=Heroku.HerokuCLI

# Or download from: https://devcenter.heroku.com/articles/heroku-cli
```

### **Step 2: Deploy**

```bash
heroku login
heroku create your-app-name
git push heroku main
heroku run python manage.py migrate
heroku run python manage.py createsuperuser
```

### **Step 3: Set Environment Variables**

```bash
heroku config:set SECRET_KEY="your-secret-key"
heroku config:set DJANGO_SETTINGS_MODULE="lostfound_project.settings_production"
```

## 🗄️ **Database Setup**

### **Render (Automatic)**

- PostgreSQL database is automatically created
- Connection string is auto-configured

### **Heroku (Manual)**

```bash
heroku addons:create heroku-postgresql:mini
```

## 📁 **Static Files**

### **Collect Static Files**

```bash
python manage.py collectstatic --noinput
```

### **Media Files**

- For production, consider using AWS S3 or similar
- Or use Render's persistent disk storage

## 🔒 **Security Considerations**

### **Production Settings Applied:**

- `DEBUG = False`
- `SECRET_KEY` from environment variables
- HTTPS redirects (uncomment when SSL is available)
- Security headers enabled
- XSS protection enabled

### **Additional Security:**

- Use strong passwords
- Enable 2FA on hosting accounts
- Regular security updates
- Monitor logs for suspicious activity

## 🚨 **Common Issues & Solutions**

### **1. Static Files Not Loading**

```bash
python manage.py collectstatic
# Ensure STATIC_ROOT is properly configured
```

### **2. Database Connection Errors**

- Check environment variables
- Verify database credentials
- Ensure database is running

### **3. Migration Issues**

```bash
python manage.py makemigrations
python manage.py migrate
```

### **4. Port Binding Issues**

- Ensure `$PORT` environment variable is set
- Check if port is already in use
